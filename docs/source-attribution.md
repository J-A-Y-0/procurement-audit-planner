# Source attribution

The [course guide](https://procurement-audit-planner.vercel.app/) supplies the project brief, six agent definitions, the extract-rules and audit-program skills, and verification/build scripts. These were used through the guide's copy-the-finished-file option and are credited to the guide.

The risk-assessment skill and register builder were implemented from the guide's design requirements. The spend-analysis scripts were produced through the spend-analyst workflow. The implementation adds tested validation for citations, input boundaries, sampling, output paths and approval revisions. The pack builder links generated documents to the final review and sign-off.

The original nine files come from the guide's [data archive](https://procurement-audit-planner.vercel.app/data.zip). They are unchanged; checksums are recorded in `evidence/source-manifest.json`.

AI tools assisted implementation and review. Human scope approval and final sign-off are recorded in the output files.
